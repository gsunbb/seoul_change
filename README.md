# 서울은 어떻게 변해 왔을까? — 배포 안내

초등 사회 「환경의 이용과 개발로 지역이 어떻게 변화했는지 탐색해 볼까요」 차시용 조사학습 웹앱입니다.
서버나 빌드 과정이 필요 없는 정적 사이트(HTML 한 장)라서 아래 방법 중 하나로 바로 올릴 수 있어요.

## 들어 있는 파일
- `index.html` : 웹앱 전체 (디자인·그림·데이터·기능 포함)
- `favicon.svg` : 브라우저 탭 아이콘
- `README.md` : 이 안내문

## 방법 1. Netlify Drop (가장 쉬움, 가입 후 1분)
1. https://app.netlify.com/drop 에 접속해 로그인합니다.
2. 압축을 푼 `seoul-change-site` 폴더를 화면에 끌어다 놓습니다.
3. 바로 `https://○○○.netlify.app` 주소가 생깁니다. Site settings에서 주소 이름을 바꿀 수 있어요.

## 방법 2. GitHub Pages (무료, 주소가 오래 유지됨)
1. GitHub에서 새 저장소(public)를 만듭니다. 예: `seoul-change`
2. Add file → Upload files로 `index.html`, `favicon.svg`를 올립니다.
3. Settings → Pages → Branch를 `main` / `(root)`로 정하고 Save.
4. 몇 분 뒤 `https://아이디.github.io/seoul-change/` 에서 열립니다.

## 방법 3. Vercel
1. https://vercel.com 에서 New Project → 폴더 업로드 또는 GitHub 저장소 연결.
2. Framework는 `Other`, 빌드 설정은 비워 둔 채 Deploy.

## 알아 두면 좋은 점
- **사진은 위키미디어 공용(Wikimedia Commons)에서 불러옵니다.** 인터넷에 연결된 상태에서 배포한 주소로 열어야 사진이 보여요. 학교 망에서 commons.wikimedia.org / upload.wikimedia.org가 막혀 있으면 사진 자리에 안내 문구가 나옵니다.
- 사진마다 저작자와 이용 조건(CC BY, CC0, 퍼블릭 도메인 등)이 다릅니다. 페이지 아래 ‘사진 출처’와 각 사진의 ‘원본’ 링크에 정리돼 있으니 지우지 말고 그대로 두세요.
- 기본 사진 대신 선생님이 찾은 사진을 쓰고 싶으면 비교 사진 아래 ‘과거/현재 사진 넣기’를 누르세요(그 브라우저에만 저장).
- 학습지 내용, 담은 단서, 선생님이 넣은 실제 사진은 **각 기기의 브라우저(localStorage)** 에만 저장됩니다. 다른 기기로 옮겨지지 않아요.
- 학생 기기에서도 실제 사진을 보여 주고 싶다면, 사진을 기기마다 넣어 주시거나 수업 화면(선생님 기기)으로 함께 보세요.
- 「학습지 내용 복사」 버튼은 https 주소에서 가장 잘 동작합니다(위 세 방법 모두 https).
- 글꼴은 Google Fonts에서 불러옵니다. 인터넷이 막힌 환경에서는 기본 글꼴로 보입니다.
